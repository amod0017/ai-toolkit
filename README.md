# ai-toolkit

Skills, agents, and utilities for AI-assisted development.

## Skills

Skills are prompt files used with [Claude Code](https://claude.ai/code) via the [Superpowers plugin](https://github.com/obra/superpowers). Install Superpowers for your agent, then drop skill files into your `.claude/skills/` directory.

### pedantic-reader

Reviews written content (blog posts, docs, READMEs, announcements) for accuracy, credibility, tone, structure, and usefulness. Searches the web to verify factual claims before accepting them.

**Invoke:** `Use the pedantic-reader skill to review this post.`

Located at [`skills/pedantic-reader/SKILL.md`](skills/pedantic-reader/SKILL.md).
